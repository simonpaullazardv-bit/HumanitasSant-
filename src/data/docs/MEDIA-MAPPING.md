# Mapping des médias HUMANITAS

Placez les fichiers dans `public/img/` :

- `dg.png` → photo du Directeur Général
- `messagedg.png` → message du DG en image
- `logo-humanitas.png` → logo principal
- `gallery/` → toutes les images de galerie, sans tri obligatoire
- `videos/` → vidéos locales, si utilisées

Les textes institutionnels peuvent être importés depuis `src/data/institutional.ts`.
